# Changelog

## 1.0.0 — 2026-11

First public release.

- Family wishlists with gift reservation (hidden from the recipient)
- Paste-a-link autofill (Open Graph, JSON-LD, Amazon fallback incl. short/affiliate links), photo upload
- "My gifts to offer" with reserved / bought / wrapped tracking and budget
- Secret Santa with exclusions and budget
- Anonymous questions on items, hidden family chat per list
- Kids' lists with co-managers
- PWA, Android share target, `/partage?url=` endpoint for iOS Shortcuts and bookmarklet
- "New" badges, "New season" archiving
- First-run setup wizard, optional `SETUP_CODE`, editable site title
- Daily SQLite backups (14 kept), `/api/health`, PUID/PGID support
- Zero npm dependencies, fonts served locally
